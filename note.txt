Integrating createRepayment with API integration

Here's a concise 40-line explanation of the code:

1. This React component (`CreateRepayment`) handles loan repayment submissions in a dashboard.
2. It uses React hooks (`useState`, `useEffect`) for state management and `useNavigate` for routing.
3. The component includes form validation, file upload handling, and API communication.
4. Users first search for a loan by ID, which triggers a GET request to fetch loan details.
5. The loan details display includes amount, balance, due date, and status (color-coded).
6. The repayment form collects: payment amount (with "Pay Full" option), payment method, and evidence upload.
7. File uploads are validated for type (JPG/PNG/PDF) and size (<5MB), with image preview.
8. Amount validation ensures payment doesn't exceed balance + 1% tolerance.
9. The form is disabled for loans with 'rejected', 'pending', or 'completed' statuses.
10. On submission, it creates FormData and sends a POST request with the repayment details.
11. The API request includes authentication via JWT from localStorage.
12. Success shows a toast notification and redirects after 3 seconds.
13. Error handling covers validation errors, API errors, and authentication issues.
14. The UI includes loading states for both the loan search and form submission.
15. Currency formatting displays amounts in Nigerian Naira (₦) without decimals.
16. Date formatting presents dates in a readable format (e.g., "May 27, 2025").
17. The component uses a `DashboardLayout` with 'Repayments' marked as active.
18. Responsive design works on mobile and desktop with a clean, user-friendly interface.
19. Visual feedback includes error messages below relevant fields and status alerts.
20. The cancel button allows users to navigate back without submitting.

The component manages complex form state while providing clear user guidance throughout the repayment process.
