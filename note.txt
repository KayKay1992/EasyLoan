Creating the myLoan component to render a user loan and created a getloan by user controller and also integrating the API.

I installed react-responsive package to handle responsiveness in smaller screen.

Explaining the controller.
Here's a concise 15-line summary of the controller's functionality:
1. Checks if requesting user is authorized (owner or admin)
2. Extracts pagination and status filter from query params
3. Fetches loans for the specified user with pagination
4. Processes each loan to:
   - Calculate endDate (createdAt + termMonths) if active and missing
   - Check if loan is unpaid past endDate
   - Update status to "defaulted" if unpaid
5. Makes necessary updates to loans in database
6. Returns processed loan data with pagination info
7. Uses createdAt instead of startDate for calculations
8. Handles loan status transitions automatically
9. Maintains data consistency with atomic updates
10. Processes loans efficiently in parallel
11. Preserves original filtering functionality
12. Includes defaultedAt timestamp for tracking
13. Provides proper error handling
14. Logs important actions for auditing
15. Returns formatted response with success status

The controller essentially automates loan lifecycle management while serving paginated results.

useUser component

In short: A reusable, error-safe way to access user data in any component wrapped in UserProvider.

1. **Custom Hook**: Creates `useUser` to access user context easily.  
2. **Context Check**: Uses `useContext` to get the current `UserContext` value.  
3. **Error Handling**: Throws an error if used outside a `UserProvider`.  
4. **Safety**: Ensures context is defined before returning it.  
5. **Simplifies Access**: Provides a clean way to consume user data across components.
